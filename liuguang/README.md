# dsh-theme-liuguang

**琉光 Liuguang** — a skin for the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) GUI with **two switchable design languages**:

- **液态玻璃 / Liquid Glass** — translucent panes, inner-lit glass beads, pointer specular, OKLCH + WCAG-audited palettes
- **苏联构成主义 / Soviet Constructivism** — cream/ink/red poster geometry, ruled code blocks, hard offset shadows, one typeset metric margin

Plus a personalization panel (`✦`), drop-in CSS skin packs, and a seven-expression whale-girl desktop pet.

## Install

```sh
dsh plugin add dsh-theme-liuguang
```

Then restart DSH once. Open the `✦` button in the bottom-right corner → 外观 → 设计语言 to switch between the two languages.

Repository, screenshots and docs: <https://github.com/ShokouP/dsh-theme-liuguang>
